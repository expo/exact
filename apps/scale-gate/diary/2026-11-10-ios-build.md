# Scale gate: iOS build

## Rough

The manifest declared iOS, but the fixture had neither an Apple crate nor the TypeScript entry the generated host expects.

## Lean in

Keep its Contract UI and use the shared generated host. It needs no data queries.

## Needed

An empty data entry and generated host resolution for in-repository apps without authored Cargo crates.

## Checkpoints

Built by app name on clean Ubuntu 24.04 through its generated host. The unchanged bundle passed Apple's strict signature verification, launched on iOS 27.1, and returned its view tree and screenshot.
