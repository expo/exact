### Rough

The iOS 27.0 simulator runtime is listed by `simctl list runtimes` and cannot
boot ("runtime path not found"), so every check ran on iOS 26.5.

A headless simulator cannot open Control Center, so no press was made. What
iOS read of the controls came from its widget daemon's log:
`xcrun simctl spawn <udid> log show --predicate 'process == "chronod" AND
eventMessage CONTAINS "CHSControlDescriptor"'` lists each control's kind and
intent, and marks a URL control a launcher.

A build with `--extensions controls,intents` (no activities, so no shared
ExactCore) failed writing the extension's Info.plist, which copied an
`ExactWidgetGeneration` only a widget app has (exact2: `widgets.mjs`).

### Lean in

build that left controls out says `control-metadata` and why.
