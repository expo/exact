Set up app.json for the Exact app in this folder: its name and id, its icon and launch screen, and the assets and modules it ships. Use https://github.com/expo/exact/blob/main/docs/recipes/app-json.md as the source for each step. The Exact checkout has the same page at docs/recipes/app-json.md.

1. If this folder is not an Exact app (it has no exact.mjs and app.contract), stop and tell me.
2. If I did not say what to set (the name and id, the icon, the launch screen, a URL scheme, the appearance, the sound session), ask me. Ask me for the file of each picture: do not make one. `app.id` and `app.name` are set before the first build: if the app has a build, ask me before you change either.
3. Read app.json and the file its `$schema` names: it lists every key. Change only the keys for what I asked. `userInterfaceStyle` is `automatic` (the default), `light` or `dark`. `audio_session` is `ambient` (the default), `playback`, or `playback-mix` for sound over other apps' audio.
4. Put each file the app ships in `assets/`, and write its path from the app, with no leading slash (`image "assets/logo.png"`). For the icon, use `icons`, or `host.ios.icon` for an Icon Composer `.icon`. For the launch screen, use `host.ios.launchImage` and `host.android.launchImage`, each with `src` and `width`.
5. For a URL scheme, add a `protocol_handlers` entry and declare the route its `url` opens (`p "/p/:d"`): the whole URL arrives encoded at `%s`. For each native view, list its hyphenated tag in `modules`: a tag the list lacks is `bake-unknown-module`.
6. Never put a secret in `env`: its settings are inlined at build. Write no `entitlements` key under `host.ios` or `host.macos`, and in `infoPlist` only a key a vendor SDK reads, such as Sparkle's `SUFeedURL`. Grants derive Apple's keys (docs/recipes/permissions.md).
7. Follow the platform checks in docs/start-here.md (`bun exact.mjs docs platform checks`) for the targets in the app's AGENTS.md and app.json until they pass. Read the reports, including counted findings; a zero exit code alone does not mean clean. Fix the app, not the test. An edit to app.json, an asset, a font or a string reaches iOS only after `bun exact.mjs ios`. If a finding stays after three rounds of fixes, or the app had it before you changed anything, record it (step 8) and report it; do not keep trying.
8. When a doc was wrong or missing, or a step needed a workaround, read `bun exact.mjs feedback status`. Under `never`, keep no note. Otherwise record it: `bun exact.mjs feedback note "<what happened>"`, which goes to Expo only as that status says. Do not change the policy; tell me how many notes you kept.
9. Tell me each key you set and its value, each file you added to `assets/`, what the checks reported, and the launch command for each target platform. Tell me which pictures I must still supply.
